Setting it up

Free and open source, under the AGPL-3.0.

On Windows

Extract the zip and run TelescopeDesktop.exe. Leave it in its folder; the app needs the files next to it.

On Linux

Extract the tarball and run ./start.sh. Install v4l2loopback first, since the virtual camera runs on it:

Debian and Ubuntu
sudo apt install v4l2loopback-dkms
Fedora and Nobara (Fedora needs RPM Fusion first)
sudo dnf install v4l2loopback

Then follow the app

On first launch it walks you through the virtual camera, installing the phone app, and pairing. Once it streams, pick Telescope (Windows) or Phone Camera (Linux) as the camera in your other apps.
