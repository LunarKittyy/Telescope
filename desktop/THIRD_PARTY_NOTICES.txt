Telescope - Third-Party Notices
================================

This file lists third-party software distributed with or required to run
Telescope. Telescope's own license is unchanged by anything below - see
LICENSE in the repository root.

Bundled binaries
-----------------

UnityCapture (desktop/unitycapture/)
    DirectShow virtual camera filter for Windows.
    Copyright (c) 2018 Bernhard Schelling.
    License: MIT (see desktop/unitycapture/LICENSE).
    Source: https://github.com/schellingb/UnityCapture

Windows 11 camera (virtualcamera\TelescopeCamera.dll, source in desktop/virtualcamera/)
    Telescope's own code, under Telescope's license. Its structure follows
    Microsoft's VirtualCamera sample.
    Sample: Copyright (c) Microsoft Corporation. License: MIT.
    Source: https://github.com/microsoft/Windows-Camera/tree/master/Samples/VirtualCamera

Android SDK Platform Tools (not included)
    On Windows, adb.exe is downloaded from Google when you ask for it (Get adb), and kept in
    %LOCALAPPDATA%\Telescope\platform-tools with Google's NOTICE.txt.
    Copyright (c) Google LLC.
    License: Android Software Development Kit License Agreement.
    https://developer.android.com/studio/terms

Python runtime dependencies
-----------------------------

These are installed from PyPI at setup time (desktop/requirements.txt) - on
Linux by start.sh into a Telescope-owned virtual environment, on Windows
they are bundled into the TelescopeDesktop app folder by PyInstaller. Each project's
own repository/PyPI page has the authoritative license text.

PyQt6 (https://pypi.org/project/PyQt6/)
    Copyright (c) Riverbank Computing Limited.
    License: GPL v3 (a commercial license is also available from Riverbank
    Computing; this project uses the GPL-licensed distribution).

opencv-python-headless (https://pypi.org/project/opencv-python-headless/)
    License: Apache License 2.0.

numpy (https://pypi.org/project/numpy/)
    License: BSD 3-Clause.

pyvirtualcam (https://pypi.org/project/pyvirtualcam/)
    License: MIT.

qrcode (https://pypi.org/project/qrcode/)
    License: BSD 3-Clause.

ifaddr (https://pypi.org/project/ifaddr/)
    Copyright (c) 2014 Stefan C. Mueller.
    License: MIT.

av (PyAV, https://pypi.org/project/av/)
    Decodes the phone's H.264 stream. License: BSD 3-Clause.
    Its wheels bundle FFmpeg (https://ffmpeg.org/), built with GPL components
    including x264, so the bundled FFmpeg is under the GNU GPL v2 or later.
    That is compatible with Telescope's AGPL-3.0. FFmpeg's source is at
    https://ffmpeg.org/download.html; PyAV's build scripts name the exact
    versions (https://github.com/PyAV-Org/pyav-ffmpeg).

sounddevice (https://pypi.org/project/sounddevice/, Windows only)
    Plays the phone's microphone into VB-Cable. License: MIT.
    Its Windows wheel bundles PortAudio (http://www.portaudio.com/), MIT-style license.

VB-Audio Virtual Cable is not distributed with Telescope. On Windows the
Microphone card can download VB-Audio's own package from vb-audio.com and
open VB-Audio's own setup, unchanged, when the user asks it to; it's
installed under VB-Audio's terms.
    The origin of VB-CABLE : www.vb-cable.com.
    VB-CABLE is a donationware, all participations are welcome.

cryptography (https://pypi.org/project/cryptography/)
    Makes the Browser camera's self-signed certificate. License: Apache 2.0
    or BSD 3-Clause, at your choice. Its wheels bundle OpenSSL
    (https://www.openssl.org/), Apache License 2.0, and depend on cffi
    (https://pypi.org/project/cffi/), MIT.

aiortc (https://pypi.org/project/aiortc/)
    Receives the Browser camera's video and sound over WebRTC.
    Copyright (c) Jeremy Lainé. License: BSD 3-Clause.
    Installed from desktop/requirements-nodeps.txt. It depends on:
    - aioice (https://pypi.org/project/aioice/), BSD 3-Clause
    - pylibsrtp (https://pypi.org/project/pylibsrtp/), BSD 3-Clause. Its wheels
      bundle libsrtp (https://github.com/cisco/libsrtp), BSD 3-Clause
    - pyee (https://pypi.org/project/pyee/), MIT
    - google-crc32c (https://pypi.org/project/google-crc32c/), Apache 2.0
    - pyOpenSSL (https://pypi.org/project/pyOpenSSL/), Apache 2.0
    - dnspython (https://pypi.org/project/dnspython/), ISC

pyrnnoise (https://pypi.org/project/pyrnnoise/)
    Brings RNNoise for the Microphone card's noise reduction. Copyright (c)
    Zhendong Peng. License: Apache 2.0. Installed from
    desktop/requirements-nodeps.txt; Telescope only uses the library it ships.
    Its wheels bundle RNNoise (https://gitlab.xiph.org/xiph/rnnoise),
    BSD 3-Clause: Copyright (c) 2007-2017, 2024 Jean-Marc Valin, (c) 2023
    Amazon, (c) 2017 Mozilla, (c) 2005-2017 Xiph.Org Foundation, (c) 2003-2004
    Mark Borgerding.

truststore (https://pypi.org/project/truststore/)
    Checks the certificates of Telescope's own downloads (updates, adb,
    VB-Cable) with the system's certificate store. Copyright (c) 2022 Seth
    Michael Larson. License: MIT.

zeroconf (https://pypi.org/project/zeroconf/)
    Copyright (c) Paul Scott-Murphy, William McBrine, Jakub Stasiak and
    python-zeroconf contributors.
    License: GNU Lesser General Public License v2.1 or later.

jeepney (https://pypi.org/project/jeepney/, Linux only)
    Talks D-Bus to the desktop portal for global keyboard shortcuts.
    License: MIT.

Exact installed versions for a given release are pinned in
desktop/constraints.txt.
