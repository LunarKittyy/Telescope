# French glossary and style

The agreed terms for French. Use them in every text. If one seems wrong, keep it and raise an objection with the reason. Never change a term silently.

Avoid: digital, supporter, customiser, sauver, initier, processer, délivrer, checker, uploader, downloader, implémenter, paramétrer, customisation, loguer, faire un clic sur

## Style
- Use the "vous" form (vouvoiement), which is the standard across popular mobile and desktop apps in French (Android, Windows, macOS, Google, Apple). Never address the user as "tu".
- Register: everyday, natural, modern French. Clear and concise, avoiding administrative stiffness, slang, or literal English calques. Use sentence case.
- Buttons and action items: use the infinitive ("Ajouter un téléphone", "Réessayer", "Démarrer"). Statuses are short states ("Prêt", "Reconnexion") or noun phrases ("Diffusion via Wi-Fi").
- Keep the English's brevity. A note saying "keep short" is a hard limit.
- Keep the English " - " (spaced hyphen). No en or em dashes.
- Punctuation and numbers:
  - Numbers take a decimal comma (2,4 GHz) and a non-breaking space before % and °C ("{level} %", "%2$d %%").
  - Non-breaking space before two-part punctuation marks (: ; ! ?).
  - Quotation marks: use French guillemets (« » with non-breaking spaces) for dialogue and prose quotes, but preserve plain ASCII quotes when enclosing code, tokens, or variables.
- Questions in dialogs: "Voulez-vous… ?"
- Card names in prose: "la carte X" (la carte Caméra du navigateur).
- Pronouns: Telescope on the desktop is "il" (le logiciel / le programme). The phone app is "l'application", so "elle".
- Keep untranslated: Telescope, OBS, adb, VA-API, PyAV, VB-Cable, VB-Audio, v4l2loopback, FFmpeg, USB, Wi-Fi, JPEG, MJPEG, H.264, fps, Nightly, file names, commands, {fields}, %1$s.
