# Hindi glossary and style

The terms agreed when this language was first drafted (October 2026), built from the Swedish glossary's term list. Use them in every text. If one seems wrong, keep it and raise an objection with the reason. Never change a term silently.

Avoid: संगणक, दूरभाष, चलभाष, अनुप्रयोग, अधोभारण, उद्भारण, संचिका, दृश्यपटल, चलचित्र, छायाचित्र, ध्वनिग्राही, जालस्थल, अंतर्जाल, तू, तुम, हार्डवेयर त्वरण

## Style
- Address the user with "आप" (aap-form), as used by popular apps and platforms in Hindi (Google, Android, WhatsApp, Microsoft). Use polite imperative verb forms for actions and buttons ("करें", "जोड़ें", "देखें"). Never use "तू" or "तुम".
- Register: Natural, everyday modern standard Hindi (बोलचाल की व्यावहारिक हिंदी) familiar to smartphone and computer users. Avoid stiff, hyper-Sanskritized textbook words (कठिन तत्सम/सरकारी हिंदी) as well as English street slang. Use common technical loanwords that users already know from device settings (ऐप, फ़ोन, स्क्रीन, सेटिंग, डाउनलोड).
- Prefer simpler everyday words over heavy academic ones ("सिर्फ़" or "केवल" over "मात्र", "यह" over "उक्त").
- Buttons are imperatives ("फ़ोन जोड़ें", "फिर कोशिश करें"). Statuses are short states ("तैयार") or continuous verbs ("Wi-Fi से स्ट्रीम हो रहा है").
- Keep the English's brevity. A note saying "keep short" is a hard limit.
- Keep the English " - " (spaced hyphen). No en or em dashes. Use the same quotation marks as the English (" " or “ ”).
- Numbers take a decimal point (2.4 GHz, not a comma) and no space before % and °C ("{level}%", "%2$d%%", "{temp}°C").
- In UI strings, use standard Latin punctuation (period `.`, `!`, `?`). Do not use danda (।) for short UI strings, labels, and buttons.
- Questions in dialogs: "क्या आप … चाहते हैं?" (e.g., "क्या आप डिस्कनेक्ट करना चाहते हैं?").
- Card names in prose: "X कार्ड" (e.g., "ब्राउज़र कैमरा कार्ड").
- Pronouns: Telescope on the desktop is "यह" (मशीन/सॉफ़्टवेयर). The phone app is "ऐप" (स्त्रीलिंग, "यह ऐप" / "ऐप").
- Keep untranslated: Telescope, OBS, adb, VA-API, PyAV, VB-Cable, VB-Audio, v4l2loopback, FFmpeg, USB, Wi-Fi, JPEG, MJPEG, H.264, fps, Nightly, file names, commands, {fields}, %1$s.

## Room to move (keep short)
