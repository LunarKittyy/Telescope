# Indonesian glossary and style

The agreed terms for this language, built from the Swedish glossary's term list. Use them in every text. If one seems wrong, keep it and raise an objection with the reason. Never change a term silently.

Avoid: kamu, kau, gawai, peranti, mengalirkan, aliran, bungkam, aplikasikan, pengandar, tetikus, peladen, surel

## Style
- Address the user with "Anda" (capitalized) when a direct pronoun is necessary, but prefer concise, polite imperative or impersonal phrasing that omits pronouns where natural (the standard form used by popular apps on Android and Windows, e.g. Google, WhatsApp, Microsoft). Never use "kamu" or "kau" (too informal for utility apps). Use sentence case.
- Use natural modern tech Indonesian register. Avoid stiff, bureaucratic, or purist terminology (no "gawai", "peranti", "peladen", "pengandar") and avoid slang.
- Buttons are imperatives ("Tambahkan ponsel", "Coba lagi", "Mulai streaming"). Statuses are active verbs ("Streaming via Wi-Fi") or short states ("Siap", "Terhubung").
- Keep the English's brevity. A note saying "keep short" is a hard limit.
- Keep the English " - " (spaced hyphen). No en or em dashes. Use the same quotation marks as the English.
- In prose, numbers take a decimal comma (2,4 GHz). Follow standard Indonesian typography (PUEBI/EYD) with no space before % ("{level}%", "%2$d%%"), and a space before °C ("{temp} °C").
- Questions in dialogs: "Ingin …?"
- Card names in prose: "kartu X" (kartu Kamera browser, kartu Pintasan).
- Pronouns: Telescope on the desktop is "aplikasi ini" (or "Telescope"). The phone app is "aplikasi ponsel" or "aplikasi ini".
- Keep untranslated: Telescope, OBS, adb, VA-API, PyAV, VB-Cable, VB-Audio, v4l2loopback, FFmpeg, USB, Wi-Fi, JPEG, MJPEG, H.264, fps, Nightly, file names, commands, {fields}, %1$s.
