# Japanese glossary and style

The agreed terms for Japanese. Use them in every text. If one seems wrong, keep it and raise an objection with the reason. Never change a term silently.

Avoid: あなた, 貴方, 〜を行う, 〜して下さい, 〜する事ができる, 〜の時, コネクト, スマートホン, パソコン, ハードウェア加速

## Style
- Do not address the user with second-person pronouns ("あなた" or "ユーザー"). Popular Japanese consumer apps (iOS, Android, Windows) address the user implicitly by omitting the subject, or use polite action requests ("〜してください").
- Register: Neutral, polite everyday Japanese (です・ます調) for dialogs, descriptions, and error messages. Avoid stiff bureaucratic language (no "〜である", no "〜だ", no redundant "〜を行う").
- Buttons are concise noun phrases or actions ("スマートフォンを追加", "再試行", "ストリーミング開始"). Statuses are short states ("準備完了") or ongoing actions ("Wi-Fi経由でストリーミング中").
- Keep the English's brevity. A note saying "keep short" is a hard limit.
- Keep the English " - " (spaced hyphen) for ranges and separators.
- Punctuation and numbers:
  - Japanese decimal separator is a dot/period (2.4 GHz), not a comma.
  - No space before % and °C ("{level}%", "%2$d%%", "45°C").
  - Quotation marks: Use Japanese corner brackets 「 … 」 (kagikakko) for quotes, UI element references, and card names.
- Questions in dialogs: "〜しますか？" (e.g. "更新しますか？", "削除しますか？").
- Card names in prose: "「X」カード" (「ブラウザー カメラ」カード).
- Pronouns and app references: Refer to Telescope on the desktop as "Telescope" or "デスクトップ アプリ", and the phone app as "スマートフォン版アプリ" (or "スマホ アプリ").
- Keep untranslated: Telescope, OBS, adb, VA-API, PyAV, VB-Cable, VB-Audio, v4l2loopback, FFmpeg, USB, Wi-Fi, JPEG, MJPEG, H.264, fps, Nightly, file names, commands, {fields}, %1$s.

## Framing speeds, slowest first (keep short)

## Room to move (keep short)
Off, Fidget, Shift, Lean, Step, Roam -> オフ、もぞもぞ、身じろぎ、傾き、一歩、歩き回り。ツールチップ: "もぞもぞ動く、椅子で姿勢を変える、体を傾ける、一歩動く、歩き回る"
