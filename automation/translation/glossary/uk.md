# Ukrainian glossary and style

The agreed terms for this language, built from the Swedish glossary's term list. Use them in every text. If one seems wrong, keep it and raise an objection with the reason. Never change a term silently.

Avoid: скачувати, закачати, включити, виключити, настройки, відмінити, нажати, перегрузити, по замовчуванню, даний, дана, дане, дані, являється, стрімити, мік, підстроювання, аплікація, в даний момент

## Style
- Address the user with "ви" (lowercase "ви", "вас", "вам", "ваш"), as popular modern apps in Ukrainian do (Android, Google, Windows). Avoid pompous capitalized "Ви" in UI strings.
- Plain, friendly, natural everyday Ukrainian. No bureaucratic stiffness (канцеляризми), no Russian calques (кальки/суржик), and no forced slang. Use sentence case.
- Buttons and action items are infinitives ("Додати телефон", "Спробувати знову", "Оновити"). Statuses are finite verbs ("Транслює через Wi-Fi") or short states ("Готово", "Звук вимкнено").
- Keep the English's brevity. A note saying "keep short" is a hard limit.
- Keep the English " - " (spaced hyphen). No en or em dashes.
- In prose, numbers take a decimal comma (2,4 ГГц) and a space before % and °C ("{level} %", "%2$d %%", "20 °C").
- Quotation marks in prose: use Ukrainian angle quotes «…» (лапки-ялинки), and „…“ for nested quotes. Use the same quotation marks as English for code, tokens, or untranslated names.
- Questions in dialogs: "Хочете …?" або "Бажаєте …?"
- Card names in prose: "картка X" (картка «Камера браузера»).
- Pronouns: Telescope on the desktop is "він" (застосунок / додаток) or "вона" (програма). The phone app is "додаток", so "він".
- Keep untranslated: Telescope, OBS, adb, VA-API, PyAV, VB-Cable, VB-Audio, v4l2loopback, FFmpeg, USB, Wi-Fi, JPEG, MJPEG, H.264, fps, Nightly, file names, commands, {fields}, %1$s.
