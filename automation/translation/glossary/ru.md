# Russian glossary and style

The agreed terms for Russian. Use them in every text. If one seems wrong, keep it and raise an objection with the reason. Never change a term silently.

Avoid: данный, настоящий, осуществлять, производить, произвести, деинсталлировать, аппликация, девайс, юзать, кликнуть, тапнуть, рестартовать, сконфигурировать

## Style
- Address the user with informal "ты" (the standard for modern Russian mobile and desktop apps like Telegram and Discord). Never use capitalized "Вы" inside UI sentences.
- Use plain, natural everyday Russian without bureaucratic stiffness (канцелярит) or slang. Use sentence case for headings and buttons (capitalize only the first word and proper nouns).
- Buttons use infinitives ("Добавить телефон", "Попробовать снова") or concise imperatives. Statuses are short states ("Готово", "Подключено") or present-tense imperfective descriptions ("Трансляция по Wi-Fi", "Ожидание").
- Keep the English's brevity. A note saying "keep short" is a hard limit.
- Keep the English spaced hyphen " - " or use an em dash " — ". Use Russian quotation marks «…» (ёлочки); if nested, use „…“ (лапки).
- In prose, numbers take a decimal comma (2,4 ГГц) and a non-breaking space before % and °C ("{level} %", "%2$d %%").
- Questions in dialogs: "Хочешь …?"
- Card names in prose: карточка «X» (карточка «Камера в браузере»).
- Pronouns: Telescope on the desktop is «он» (клиент Telescope) or «оно» (приложение). The phone app is «оно» (приложение) or «приложение на телефоне».
- Keep untranslated: Telescope, OBS, adb, VA-API, PyAV, VB-Cable, VB-Audio, v4l2loopback, FFmpeg, USB, Wi-Fi, JPEG, MJPEG, H.264, fps, Nightly, file names, commands, {fields}, %1$s.
