# Brazilian Portuguese glossary and style

The terms agreed when this language was first drafted (October 2026), built from the Swedish glossary's term list. Use them in every text. If one seems wrong, keep it and raise an objection with the reason. Never change a term silently.

Avoid: utilizador, ecrã, ficheiro, telemóvel, rato, descarregar, descarregamento, carregar (para botões), efectuar, efetuar, realizar (em vez do verbo direto), customizar, suportar (como falso cognato de compatibilidade), resumir (como falso cognato de retomar), aplicação

## Style
- Address the user with "você" (in 3rd-person singular verbs), as used by modern apps in Brazilian Portuguese (Google, Android, Windows, iOS). Keep it natural, direct, and concise; omit the pronoun "você" whenever the imperative already conveys it clearly ("Conecte o celular", "Escolha uma câmera"). Never use "tu" or "o utilizador".
- Plain, modern everyday Brazilian Portuguese. No stiff bureaucratic phrasing ("efetuar a conexão"), no excessive slang. Use sentence case for UI labels and headings (only the first letter capitalized, plus proper nouns).
- Prefer "apenas" or "só" over "somente" where space is tight, "este/esta" over "o presente", and short, direct words over long constructs.
- Buttons are imperatives or action infinitives ("Adicionar celular", "Tentar novamente", "Iniciar transmissão"). Statuses are gerunds ("Transmitindo via Wi-Fi") or short states ("Pronto").
- Keep the English's brevity. A note saying "keep short" is a hard limit.
- Keep the English " - " (spaced hyphen). No en or em dashes. Use the same quotation marks as the English ("...").
- In prose, numbers take a decimal comma (2,4 GHz) and a space before % and °C ("{level} %", "%2$d %%", "25 °C").
- Questions in dialogs: direct and friendly ("Deseja reiniciar agora?" or "Quer reiniciar agora?").
- Card names in prose: "o cartão X" (o cartão Câmera do navegador).
- Pronouns: Telescope on the desktop is masculine "ele" (o aplicativo / o Telescope). The phone app is "o app". The phone is "o celular".
- Keep untranslated: Telescope, OBS, adb, VA-API, PyAV, VB-Cable, VB-Audio, v4l2loopback, FFmpeg, USB, Wi-Fi, JPEG, MJPEG, H.264, fps, Nightly, file names, commands, {fields}, %1$s.

## Framing speeds, slowest first (keep short)
Lesma, Lento, Manso, Calmo, Suave, Firme, Ágil, Rápido, Veloz, Raio

## Room to move (keep short)
Off, Fidget, Shift, Lean, Step, Roam -> Desligado, Mexer, Ajeitar, Inclinar, Passo, Circular. O texto descritivo (tooltip): "mexer-se, ajeitar-se na cadeira, inclinar-se, dar um passo ou circular pela sala"
