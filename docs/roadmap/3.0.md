# 3.0 (29 September 2026)

Written afterwards from the commit history, the issues and the [release notes](https://github.com/LunarKittyy/Telescope/releases/tag/v3.0.0).

The biggest release up to then, and the one that turned Telescope from a camera you start by hand into something that can sit in the tray and handle itself. Most of it landed in the last week of September.

## What it was about

Using the phone's mic as a microphone on the computer. Streaming only while an app actually wants the camera, so the phone doesn't run it all day. Updates in one click for both apps, since 2.x meant downloading every release by hand. And encrypting the connection with TLS pinned to the phone's certificate at pairing, which 2.3's token alone didn't do.

Along the way came the wait screen, presets, zoom on the phone's sensor with the jump to the telephoto, Light (H.264) as the new default format, the setup checklist and the problem banners.

## Ideas from users

Several of these were asked for while 3.0 was being built:

- Zoom that uses the real lenses behind a phone's main camera ([#14](https://github.com/LunarKittyy/Telescope/issues/14))
- Your own picture or GIF when there's no feed ([#34](https://github.com/LunarKittyy/Telescope/issues/34)), which became the wait screen
- Stopping when the app using the camera lets go of it ([#35](https://github.com/LunarKittyy/Telescope/issues/35)) and clearer start and stop options ([#68](https://github.com/LunarKittyy/Telescope/issues/68)), which became Automatic streaming
- Starting while the phone is locked ([#69](https://github.com/LunarKittyy/Telescope/issues/69)), which became **Wait for my computer**
- A donation link ([#70](https://github.com/LunarKittyy/Telescope/issues/70)), which became the Ko-fi link

## The cost

Pairings and per-phone settings from 2.3 didn't carry over, and the phone app had to be uninstalled once because it was signed with a new key.

## Left open

Light had Auto or a bitrate you set by hand (up to 30 Mbps), and nothing noticed when the connection couldn't keep up ([#88](https://github.com/LunarKittyy/Telescope/issues/88) was opened the day 3.0 came out). Windows came as a zip folder with no installer.
