# 3.4 (11 and 12 October 2026)

Written afterwards from the commit history, the issues and the release notes for [3.4.0](https://github.com/LunarKittyy/Telescope/releases/tag/v3.4.0) and [3.4.1](https://github.com/LunarKittyy/Telescope/releases/tag/v3.4.1).

## What it was about

Three separate things that happened to be ready together.

Keyboard shortcuts for almost every control, each with its own settings (one key can raise exposure by 1 EV while another sets it back to 0). They're global on Windows and on Linux desktops with the global shortcuts portal, and `telescope --action` covers the other desktops.

A real Windows installer that installs per user with no admin, with zip copies moving themselves over to it on the next update. This finally replaced the zip folder 3.0 shipped with.

Low light, which lets auto exposure slow the camera down in a dark room and runs noise reduction at its best.

## Also in 3.4.0

Dynamic bitrate started lowering the frame rate too (down to 15 fps) when the connection can't carry sharp frames, which [3.1](3.1.md) had left out. adb stopped coming with the Windows download and gets fetched from Google on request instead. The window hidden in the tray stopped polling the phone every 3 seconds, which had kept waking a waiting phone's Wi-Fi.

## 3.4.1

Google blocks its Android tools in some countries, so getting adb failed there with a bare 404 ([#180](https://github.com/LunarKittyy/Telescope/issues/180)). 3.4.1 explains that and adds **Use my own adb…** for an adb from somewhere else.

## Left open

Each frame rate step Dynamic took restarted the phone's camera for a moment.
