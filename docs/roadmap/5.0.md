# 5.0 (3 November 2026)

Started on 28 October 2026 right after 4.4.2 ([release notes](https://github.com/LunarKittyy/Telescope/releases/tag/v5.0.0)) as a prototype to see whether the desktop app would be lighter in Rust and Slint. It was, and the prototype turned into a full port of the Python app over about 1100 commits. PyAV 19, which had moved on from 4.4, isn't needed any more since nothing uses Python now.

## The desktop app in Rust

Every part of the Python app got ported with its tests, and the phone app and the protocol stayed the same so paired phones keep working. It starts about three times faster, uses less CPU while streaming and takes about a tenth of the disk space. `rust/FINDINGS.md` has the measurements and `rust/ARCHITECTURE.md` how it's put together. The phone side got a few fixes along the way (mic permission mid-stream, the preview following rotation and the lens changing while the phone is hot).

Before the release it went through several rounds of code review, a security pass and a run on a real phone and a Windows VM. The fixes from those went in with it.

## Plugins in Lua

Plugins are Lua now, with shaders in WGSL and cards in `.slint`, and Python plugins don't run any more. Lua patterns run on a Rust port of Lua's own matcher with a work limit to stop a slow pattern from freezing the app. `check-plugin` checks a plugin from the terminal.

## Going back to Python

Settings has a **Go back to the Python version** button pinned to 4.4.2. It copies the settings aside first and turns off 4.4.2's own update check. An AppImage opens the 4.4.2 download page instead, since it can't swap itself.

## AppImage

A Linux AppImage for Ubuntu 22.04, Debian 12, Fedora 36 or newer that doesn't need libfuse2, next to the tarball.
