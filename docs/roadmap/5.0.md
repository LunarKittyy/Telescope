# 5.0 (3 November 2026)

Started on 28 October 2026 right after 4.4.2 ([release notes](https://github.com/LunarKittyy/Telescope/releases/tag/v5.0.0)) as a prototype to see whether the desktop app would be lighter in Rust and Slint. It was, and the prototype turned into a full port of the Python app over about 1100 commits. PyAV 19, which had moved on from 4.4, isn't needed any more since nothing uses Python now.

## The desktop app in Rust

Every part of the Python app got ported with its tests, and the phone app and the protocol stayed the same so paired phones keep working. It starts about three times faster, uses less CPU while streaming and takes about a tenth of the disk space. `rust/FINDINGS.md` has the measurements and `rust/ARCHITECTURE.md` how it's put together. The phone side got a few fixes along the way (mic permission mid-stream, the preview following rotation and the lens changing while the phone is hot).

Before the release it went through several rounds of code review, a security pass and a run on a real phone and a Windows VM. The fixes from those went in with it.

## Plugins in Lua

Plugins are Lua now, with shaders in WGSL and cards in `.slint`, and Python plugins don't run any more. Lua patterns run on a Rust port of Lua's own matcher with a work limit to stop a slow pattern from freezing the app. `check-plugin` checks a plugin from the terminal.

## Going back to Python

Settings has a **Go back to the Python version** button pinned to 4.4.2. It copies the settings aside first and turns off 4.4.2's own update check. An AppImage opens the 4.4.2 download page instead, since it can't swap itself.

## AppImage

A Linux AppImage next to the tarball, for Ubuntu 22.04, Debian 12, Fedora 36 or newer and rolling distros like Arch. It doesn't need libfuse2.

## 5.0.1 (3 November 2026)

A patch on the same day ([release notes](https://github.com/LunarKittyy/Telescope/releases/tag/v5.0.1)) for the Webcam card and a few texts.

- Webcam card sliders broke off a drag right after it started, so only clicking worked. Its Slow down in the dark switch was also squashed to the height of its text
- Status texts that talked as if the app were doing the waiting got reworded, like Restart required on a plugin whose switch changed

## 5.0.2 (3 November 2026)

Another patch on the same day ([release notes](https://github.com/LunarKittyy/Telescope/releases/tag/v5.0.2)), mostly for keyboards and screen readers.

- Tab walks one stable cycle through the whole window, including what's scrolled out of view, and scrolls to what it reaches
- Dropdowns open and pick from the keyboard, and Space and Enter work on every switch and button
- Every control has a name for screen readers, and sliders, colour wheels, the curve, the pan pad and the picture editor say where they're set
- Mirror, flip and half turn run on the CPU. They're cheap there, and a graphics card busy with a game or OBS held up every frame even with all effects off

## 5.0.3 (3 November 2026)

A third patch on the same day ([release notes](https://github.com/LunarKittyy/Telescope/releases/tag/v5.0.3)) with what was left of the same two things.

- Zoom and stretch moved to the CPU too, for the same reason
- Hovering a dropdown moves its keyboard highlight, the phone dropdown says Pick a phone when none is picked and the Settings sidebar scrolls in a short window
- Screen readers read each switch's name once and no longer read out the hidden words Settings search uses

## 5.0.4 (4 November 2026)

A patch ([release notes](https://github.com/LunarKittyy/Telescope/releases/tag/v5.0.4)) for frames dropping on Windows while a game is in front.

- Windows throttled Telescope in the background and decoding on the graphics card got stuck behind the game. Telescope now opts out of power throttling and asks for a higher priority, and when the card still stalls the processor decodes for a few minutes before the card gets another try
- At most about 2 seconds of stream waits for the decoder, and a short hiccup no longer makes Dynamic drop the bitrate to the bottom
- Copy diagnostics got a machine summary, a timeline, the worst moments and each frame step's time, and hides more personal details (home folders in every spelling, MAC addresses, emails and device names)

## 5.0.5 (4 November 2026)

A patch ([release notes](https://github.com/LunarKittyy/Telescope/releases/tag/v5.0.5)) with webcam controls on Windows.

- The Webcam card shows the camera's own controls on Windows too, not only on Linux. An antivirus blocking the camera now says so instead of claiming another app is using it, and the list leaves out uncompressed sizes that can't keep up
- Loading, renaming and deleting from the Presets menu did nothing when clicked
- The Windows title bar is dark with Telescope's icon
- "Device" now means anything that streams to Telescope (a phone, a browser or a webcam), so the picker says Pick a device and Add phone became Add device
